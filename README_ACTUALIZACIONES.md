# Cazador Amazon — canal de actualizaciones

Este repositorio es el canal público de distribución. El código fuente privado y los datos del usuario no se publican aquí.

## Contrato de publicación

La versión se distribuirá como ZIP mediante una URL HTTPS estable. El manifiesto indicará versión, URL y SHA-256 del ZIP. Antes de activar la instalación automática, el cliente deberá validar la autenticidad del manifiesto mediante firma digital con clave pública integrada, además del hash del ZIP.

## Estado actual

**NO HAY NINGUNA ACTUALIZACIÓN PUBLICADA.** No crear un manifiesto que apunte a un archivo inexistente. No introducir tokens de GitHub ni contraseñas en ejecutables.

## Protección de datos

El actualizador debe preservar bases de datos, configuración y archivos del usuario; realizar copia de seguridad y contar con recuperación ante fallos de instalación.
